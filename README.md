# 평가계획 검토기

고등학교 교과(목)별 평가계획서(hwpx)를 넣으면 형식 규칙과 수치 검산을 자동으로 점검하는 단일 HTML 도구입니다.

**바로 쓰기 → https://hong-jame.github.io/pyeongga-checker/**

설치도 인터넷 연결도 필요 없습니다. 파일은 브라우저 안에서만 처리되며 어디에도 전송되지 않습니다.

## 무엇을 점검하나

**수치 검산** — 표의 병합 셀을 원래 격자로 복원해 계산합니다.

- 정기시험과 수행평가 반영비율 합이 100%인지
- 영역별 만점 비율의 합이 각 유형의 반영비율과 맞는지
- 수행평가 영역 만점이 반영비율과 같은지 (20% 영역이면 20점)
- 반영비율 표의 수행평가 영역 만점 합계와 세부기준의 만점 합계가 맞는지
- 논술형 반영비율의 구성 값 합과 표기된 합계가 맞는지, 정기시험 한 차수에 몰려 있지 않은지
- 성취기준 코드 형식, 평가계획에만 있고 교수학습 운영계획에 없는 성취기준

**범교과 학습 주제 시수** — 범교과 시수 배분표(xlsx)를 함께 넣으면 실행됩니다.

- 배분표의 `평가계획에 입력할 내용`과 `편성시수`를 기준으로 삼습니다. 배분표는 학기마다 교과마다 달라지므로 도구에 고정해 두지 않고, 그때그때 엑셀 파일을 그대로 읽습니다
- 학년과 교과명으로 배정 항목을 고르고, 전교과 필수 항목은 모든 과목에 적용합니다
- 계획서의 `(생활안전교육 1시수)` 같은 표기를 주제별로 합산해 기준 시수와 대조합니다. 한 주제를 여러 차시에 나눠 적어도 합계로 판정합니다
- `시수`, `시간`, `차시` 표기와 띄어쓰기 차이를 모두 인식합니다
- 누락, 부족, **시수 미표기**(주제는 썼으나 시수가 없음), 초과를 구분합니다
- 기준 학기는 계획서의 학기를 따르거나 직접 고를 수 있습니다

**필수 항목 존재 여부**

- 지필평가 용어 잔존 (2026학년도부터 정기시험으로 변경)
- AI 활용 기본 원칙 3항목
- 분할점수 산출 방식(고정 또는 추정) 명시, 성취도 5단계와 3단계 중복 작성
- 정의적 능력 평가, 미응시자와 학적변동자 성적처리, 기본점수와 장기 미인정 결석자
- 1·2학년 학기 단위 성취수준, 공통과목 최소 성취수준(40%)
- 성취수준 A~E 진술 빈칸, 평가 시기 빈칸
- 채점기준의 지양 표현 (과제 수행률, 분량, 감점, 지적 횟수, 출석률)
- 양식의 안내 문구와 메모 잔존

## 판정 4단계

| 표시 | 뜻 |
|---|---|
| 오류 | 고쳐야 하는 항목 |
| 경고 | 검토가 필요한 항목 |
| 판정 불가 | **표 구조를 읽지 못해 검산하지 못한 항목. 통과가 아니므로 직접 확인해야 합니다** |
| 통과 | 규칙을 만족 |

성취기준 원문과의 대조(임의 변경 여부)와 채점기준의 구체성은 자동 판정 대상이 아닙니다.

## hwpx만 가능합니다

`.hwp`(바이너리)는 표 구조를 읽을 수 없어 검산이 되지 않습니다. 한글에서 **다른 이름으로 저장 → 파일 형식을 한글 문서 (\*.hwpx)** 로 저장한 뒤 넣어 주세요.

학년별 통합본과 과목별 개별 파일 모두 인식하며, 통합본은 과목을 자동으로 분리해 과목별로 채점합니다.

## 기타

- 외부 라이브러리를 쓰지 않습니다. ZIP 해제는 브라우저 내장 `DecompressionStream`을 사용하므로 크롬이나 엣지 최신 버전에서 열어 주세요.
- 결과는 필터로 추려 보거나, 수정 요청 문구로 복사하거나, 인쇄와 PDF로 남길 수 있습니다.
- 규칙은 2026학년도 경기도교육청 평가계획 양식과 고등학교 성취평가제 모니터링 체크리스트를 기준으로 정리했습니다. 지침이 바뀌면 규칙도 손봐야 합니다.
